# MykoVolt Platform

This directory documents the platform architecture, layer specifications, and research roadmap.

```
platform/
├── architecture/
│   ├── overview.md        # Platform vision, architecture layers, specifications
│   ├── power.md           # Power systems (fungal MFC, Mg-Air, hybrid)
│   ├── compute.md         # Compute and communication layers
│   └── manufacturing.md   # Manufacturing pipeline and roadmap
└── README.md              # This file
```

The platform is independent of any specific application. The DevKit (`applications/devkit/`) is the first instantiation.
