Das Problem

Es gibt Umgebungen, in denen Sensoren dringend benötigt werden, aber keine Batterie darf:

  • Kompost: Li-Ion im Kompost zertifiziert die ganze Charge
  • Beton: Sensor wird eingegossen — nie wieder erreichbar
  • Deponie: Batterien laugen aus — verboten
  • Wundauflage: Li-Ion ist nicht biokompatibel
  • CO2-Zertifizierung: "Wir haben tausend Li-Ion vergraben, um zu beweisen, dass der Boden gesund ist" — unglaubwürdig
Heute: Keine Lösung
Diese Umgebungen sind Sensor-Whitelands
MykoVolt: Vergängliche Elektronik

Die Plattform

MykoVolt ist keine Produktfirma. Es ist eine offene Plattform für vergängliche Sensorik:

LayerJetzt (DevKit v0.1)Future
StromPilz-MFC (25 µW)Biologisch + Hybrid
SensorKapazitiv (FDC1004)Temp, Chem, Vibr.
KommunikationNFC (2-5 cm)BLE, Passiv-RF
LeiterplatteFR-4 (wiederverwendbar)Zellulose (kompostierbar)
Kosten~EUR 0,15/Pressling~EUR 0,01/Node

Jeder Layer kann unabhängig verbessert werden. Die Plattform bleibt.

Enthalten im DevKit:

  • PCB-Design (30x20mm, 4-Layer, 57 Komponenten)
  • Firmware (STM32L011, Zero Warnings)
  • Simulations-Suite (11 Level, 95 Tests)
  • PCB-Generator (YAML-Konfig, CLI, CI/CD)
  • Design-Konfiguration (design_rules.yaml)
  • Gerber-Export (JLCPCB-ready)

DevKit: EUR 49-99 · Forscher bauen damit die nächsten Anwendungen.

Anwendungen (Heute & Morgen)

Jetzt
DevKit für Forschung

Erstes Produkt. Forscher experimentieren mit Pilz-Batterien, kompostierbarer Sensorik, ephemerer Elektronik. EUR 49-99/Kit.

2028+
Kompost-Überwachung

Sensor im Komposthaufen. Pilz-Batterie wird selbst Kompost. Li-Ion ist in industriellem Kompost verboten. Regulatorischer Moat.

2030+
Infrastruktur-Monitoring

1.000 Sensoren in einer Betonladung. Nach 7 Tagen ausgelesen, für immer eingeschlossen. Kein Li-Ion im Beton.

2030+
CO2-Zertifizierung

Tausende Sensoren auf regenerativen Äckern. Die Batterie kompostiert. Der Sensor wird ausgelesen. Die Daten sind der Zertifikatsnachweis.

Langfristig
Ökologische Forensik

Sensoren, die wie Kieselsteine aussehen. Überwachung von Wildererei, illegalem Holzeinschlag, Umweltverschmutzung. Sie verschwinden, wenn niemand sie findet.

Vision
Ephemere Sensor-Staub

€0,01/Node. Gedruckte Schaltungen. Bodenbetrieben. Kein Ökosystem stört. Keine Rückholung. Kein Abfall.
