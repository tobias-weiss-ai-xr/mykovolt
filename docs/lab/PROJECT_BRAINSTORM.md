- Current power density: **50-200 uW/cm2**

- Cost target: **$0.15-0.50 per unit**

- Mechanisms: Electron transfer via nanomaterials, metabolic pathways, biofilm interactions
- Current efficiency: **~1-5%**
- Target efficiency: **10-15%**
- Challenges: Low power output, long start-up time, electrode fouling
