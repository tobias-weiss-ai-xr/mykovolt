# MykoVolt Research — Agent Guidelines

> These rules keep the MFC literature corpus consistent and reproducible.
> Follow them whenever you touch `research/`.

## Pipeline (never edit README by hand)

```
config/taxonomy.yaml ──► papers.yaml ──► validate_papers.py
                          │   ▲              │
                          ▼   └── fetch_* ───┘
                   generate_readme.py ──► README.md (auto)
                          │
                          ▼
                  standard_stats.py ──► statistics.json, papers.json
              analysis/generate_reports.py ──► docs/research/*.md
```

## Rules

1. **`papers.yaml` is the source of truth** for the paper corpus.
2. **Never edit `README.md` directly** — it is generated by `scripts/generate_readme.py`.
3. **Every paper needs** a valid `category` + `subcategory` (from `config/taxonomy.yaml`),
   a `date` in `YYYY-MM`, and a normalized `url`.
4. **Always validate before commit:**
   ```bash
   cd research
   python3 scripts/validate_papers.py
   ```
5. **After adding papers, regenerate everything:**
   ```bash
   python3 scripts/generate_readme.py
   python3 scripts/standard_stats.py
   python3 scripts/analysis/generate_reports.py
   ```
6. **Discovery commands (optional, rate-limit aware):**
   ```bash
   python3 scripts/fetch/fetch_other_sources.py      # CrossRef/EuropePMC/DBLP
   python3 scripts/fetch/fetch_openalex_bulk.py --per-category 40 --months 120
   python3 scripts/fetch/fetch_new_papers.py --local --months 60   # arXiv (may 429 — retry)
   ```
7. **Known fetch pitfalls:**
   - arXiv returns `429` under load — wait ~45 s and retry, or rely on OpenAlex.
   - Supplementary DOIs (`.s001`) and SSRN preprints don't resolve via CrossRef —
     fill `date` via OpenAlex title search or manually.
   - After fetch, run the cleanup pass (HTML tags in titles, missing dates).

## Taxonomy (one place to change)

All categories, subcategories, and discovery queries live in
`research/config/taxonomy.yaml`. Change it there, then re-run the pipeline.
